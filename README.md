# Livre Escolha Utilities

Este projeto, desenvolvido em **Java** com **Swing**, foi originalmente criado para fornecer uma variedade de ferramentas automatizadas, incluindo:

- **Organização de Arquivos e Pastas**: Organização automatizada de arquivos baseados em critérios específicos.
- **Renomeação de Arquivos**: Opções para renomear arquivos com base em configurações definidas pelo usuário.
- **Processamento de Planilhas**: Mesclagem e manipulação de dados em planilhas Excel.
- **Substituições Simples**: Renomeação ou edição de arquivos utilizando padrões predefinidos.

## Status do Projeto

⚠️ Este projeto **não receberá mais atualizações** e foi oficialmente migrado para **Python**, com melhorias de desempenho e funcionalidades adicionais. O novo projeto está disponível no repositório:

➡️ [LE_Helper_Py](https://github.com/LuanVm/LE_Helper_Py)

Recomendamos que todos os usuários utilizem a nova versão, que oferece uma interface aprimorada com **PyQt6** e suporte a tecnologias mais modernas.

## Tecnologias Utilizadas

- **Java 8**
- **Swing**: Interface gráfica.

---

## Funcionalidades Anteriores

### Organização de Arquivos e Pastas
- Organização automatizada baseada em regras e padrões definidos.
- Suporte à criação de subpastas para diferentes categorias de arquivos.

### Renomeação de Arquivos
- Renomeação em massa com personalização.
- Opção de ordenar arquivos numericamente e renomeá-los em sequência.

### Processamento de Planilhas
- Consolidação de dados em planilhas Excel.
- Suporte a múltiplas abas e equalização de dados em colunas específicas.

### Substituições Simples
- Edição automatizada de nomes de arquivos ou conteúdos com base em critérios definidos.

## Como Executar (Versão Descontinuada)

1. Certifique-se de ter o **Java 8** instalado.
2. Compile o código-fonte utilizando sua IDE favorita (como **IntelliJ IDEA** ou **Eclipse**).
3. Execute a aplicação a partir da classe principal `TelaPrincipal`.
